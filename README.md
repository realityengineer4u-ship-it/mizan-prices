# نشرة أسعار ميزان البناء (بتتحدث لوحدها كل يوم)

الأداة بتقرأ الملف `prices.js` من:
https://cdn.jsdelivr.net/npm/mizan-bina-prices@latest/prices.js
أول ما تتفتح. لو مش متاح (مفيش نت / الملف مش موجود) بتشتغل بآخر أسعار مدمجة فيها.

## التشغيل لأول مرة (مرة واحدة بس)
1. اعمل حساب على npmjs.com ← Access Tokens ← Generate New Token ← نوع **Automation** وانسخه.
2. في الريبو: Settings ← Secrets and variables ← Actions ← New repository secret ← الاسم `NPM_TOKEN` والقيمة التوكن.
3. Actions ← «تحديث أسعار ميزان البناء» ← Run workflow. أول تشغيل بينشر الباكدج، ومن بعدها بيشتغل لوحده كل يوم 8:30 الصبح بتوقيت دبي.

## بيعمل إيه كل يوم
- يدوّر على نشرات أسعار الحديد والأسمنت المصرية المنشورة آخر 36 ساعة، ويستخرج أسعار عز/بشاي/السويس/الجارحي/المصريين/المراكبي ومتوسط الأسمنت.
- حدود أمان: أي تغيير أكبر من 8% في يوم بيترفض، ولازم 4 شركات على الأقل للحديد ومصدرين للأسمنت.
- لو نجح: يحدّث `data/current.json` و`prices.js` وينشر نسخة جديدة ويمسح الكاش — والأداة تعرض «أسعار لحظية · آخر تحديث: …».
- لو فشل: مفيش حاجة بتتغير، والأداة بتفضل على آخر أسعار سليمة.

## الإمارات والسعودية وباقي الخامات
أسعارهم شهرية. عدّل `data/overrides.json` من GitHub (حتى من الموبايل)، مثال:
{"AE":{"steel":{"v":3200,"src_ar":"Emirates Steel أكتوبر 2026","src_en":"Emirates Steel October 2026"}}}
أول ما تحفظ، التحديث بيشتغل لوحده (حد الأمان هنا 25%).

## اختبار
node scripts/test.mjs            ← يختبر استخراج الأرقام
MIZAN_OFFLINE=1 node scripts/update.mjs   ← تشغيل من غير نت (overrides بس)

ملاحظة: لو غيّرت اسم الباكدج في package.json لازم يتغير في رابط الأداة كمان.
